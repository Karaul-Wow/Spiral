# Spiral Matrix Loader

Асинхронная загрузка матрицы по URL и обход её по спирали против часовой стрелки.

## Особенности
- Асинхронная загрузка через `aiohttp`.
- Парсинг «грязного» текста с рамками и спецсимволами.
- Рекурсивный парсер, спрятанный за чистым публичным интерфейсом.
- Спиральный обход против часовой стрелки для матриц любой размерности.
